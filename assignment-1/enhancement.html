Enhancement 1 - CSS Variables

To ensure a consistent look across all pages, a colour scheme is generated with coolors.co. Each colour is assigned a functional name (e.g. dark1, lightText, lightBackground and mid1) and defined as root variables.

Defining the colour scheme functionally as variables allows

  • The subsequent CSS can use the colour scheme based on their intended function to ensure it is applied consistently
  • Creating a single source of colour values to reduce risk of errors in colour values
  • A single point to edit to update/experienment with different colours

Source: w3schools

Enhancement 2 - CSS Accordion

Accordion is a common element that allows collapsable elements on the web page. I used an accordion to add additional information for a product.

The following HTML and CSS elements/properties are used to implement the accordion

  • A standalone checkbox and linked label to toggle the state of the accordion
  • content height set in CSS depending on the state of the checkbox
  • A short transition time is set to create a smooth animated transition between the closed and open state
  • ::after, transition and transform are used to create the drop down arrow

It is noted that this technique uses nested CSS to update the height of the content based on the state of the checkbox However, despite its implementation in all major browsers, nested CSS currently remains a working draft and it triggers a parsing error on the CSS validator.

Source: https://alvarotrigo.com/blog/css-accordion/
